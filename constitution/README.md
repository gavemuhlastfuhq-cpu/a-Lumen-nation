# Lumen Constitution

The Constitution is the normative source for Lumen's architectural
and behavioral constraints.

The application must enforce constitutional rules through deterministic
software wherever technically possible.

AI counsel may interpret, analyze, challenge, and recommend.

AI counsel does not possess unrestricted authority to override
constitutional policy.

Core principles:

1. Human autonomy
2. Privacy by minimization
3. Evidence before conclusion
4. Provenance before amplification
5. Uncertainty must remain visible
6. Good-faith error is not equivalent to deception
7. Identity is not authority
8. Verification is not truth
9. Popularity is not evidence
10. Correlation is not causation
11. Emergency authority is narrow and auditable
12. High-impact actions require deterministic authorization
13. No secret unrestricted administrative access
14. User data must be exportable
15. Constitutional changes require versioned review
