# Lumen Evidence Architecture

The following concepts remain distinct:

Observation
Claim
Evidence
Source
Provenance
Interpretation
Contradiction
Conclusion
Decision

Evidence assessments are versioned.

Evidence status is epistemic rather than social.

Suggested status values:

- UNASSESSED
- SUPPORTED
- STRONGLY_SUPPORTED
- CONTESTED
- UNRESOLVED
- CONTRADICTED
- DISPROVEN

A status always requires supporting metadata.
